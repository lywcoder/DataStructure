# 第 19 章：动态规划

本章学习动态规划（Dynamic Programming，DP）的核心思想，并用五个实验把“定义状态、写转移、确定计算顺序、恢复答案”串起来：0/1 背包、矩阵乘法链、所有顶点对的最短路径、带负权边的单源最短路径，以及网组的最大无交叉子集。全部代码兼容 C++11，算法在 [`dynamicProgramming.hpp`](./dynamicProgramming.hpp)，运行示例在 [`chapter19Demo.cpp`](./chapter19Demo.cpp)，断言测试在 [`testChapter19.cpp`](./testChapter19.cpp)。

## 1. 动态规划的主要思想

许多问题可以拆成更小的子问题，而且不同求解分支会反复遇到同一个子问题。动态规划**只计算并保存每个子问题的答案一次**，再从已知的小问题答案推导大问题答案。用于最优化时，还需要**最优子结构**：大问题的一个最优解包含相应子问题的最优解。

设计一个 DP，依次回答四个问题：

1. **状态是什么？** 用少量参数完整描述一个子问题。例如 `dp[i][c]` 表示前 `i` 件物品在容量 `c` 下能取得的最大价值。
2. **最后一步有哪些选择？** 把选择逐一列出，写出状态转移式，不能遗漏可行情况。
3. **边界与计算顺序是什么？** 先确定最小子问题的值，再按依赖关系填表。可以自顶向下记忆化搜索，也可以自底向上制表；本章使用制表。
4. **怎样得到具体解？** 最优值通常只是一个数。若还要路径、所选物品或加括号方案，就保存决策或逆向比较状态。

DP 与贪婪算法都可能利用最优子结构，但 DP 会保留多个必要状态，比较不同选择；贪婪算法只按一个局部规则立即决定。第 17 章的背包反例说明：容量 `50` 时，按单位重量价值选 `(10,60)` 和 `(20,100)` 仅得 `160`，而选 `(20,100)` 与 `(30,120)` 得 `220`。DP 不会因为先选了第一件就丢掉后一种方案。

下文统一用 **0 起始下标** 表示代码里的物品、顶点和端点；矩阵名 `A1, A2, …` 为便于阅读使用 1 起始编号。

| 实验 | 状态 | 主要时间 | 主要空间 |
| --- | --- | --- | --- |
| 0/1 背包 | 已考虑物品数、剩余容量 | `O(nC)` | `O(nC)` |
| 矩阵乘法链 | 连续矩阵区间 `[i,j]` | `O(n³)` | `O(n²)` |
| 所有顶点对最短路径 | 允许的中间顶点范围、起点、终点 | `O(V³)` | `O(V²)` |
| 带负权边的单源最短路径 | 最多经过的边数、终点 | `O(VE)` | `O(V)` |
| 网组最大无交叉子集 | 以第 `i` 条线结尾的最优子集 | `O(n²)` | `O(n)` |

其中 `C` 是整数容量，`V` 是顶点数，`E` 是边数。背包的 `O(nC)` 依赖容量的**数值**，因此属于伪多项式时间；当 `C` 很大时，二维表也会占用大量内存。

## 2. 实验一：0/1 背包

### 问题背景

有 `n` 件不可拆分的物品。第 `i` 件重量 `w[i] > 0`，价值 `v[i] ≥ 0`；背包容量为非负整数 `C`。每件物品至多取一次，要求总重量不超过 `C`，总价值最大。仓储选货、有限预算项目选择都可抽象成这个模型。

### 状态与转移

令 `dp[i][c]` 为**只考虑前 `i` 件物品、容量为 `c`**时的最大价值。第 `i` 件物品（代码下标 `i-1`）只有两种选择：

```text
不选：dp[i-1][c]
选：  dp[i-1][c-w[i-1]] + v[i-1]，仅当 w[i-1] ≤ c
dp[i][c] = 上述可行方案的最大值
dp[0][c] = 0
```

“选”时一定读**上一行**，这样同一件物品不会重复使用。按 `i=1..n`、`c=0..C` 填表。求得 `dp[n][C]` 后，从 `(n,C)` 倒推：若 `dp[i][c] == dp[i-1][c]`，按约定不选第 `i` 件；否则记录它，并把 `c` 减去其重量。最后反转所记录的下标。

例：物品为 `(重量,价值) = (10,60),(20,100),(30,120)`，容量 `50`。最优值 `220`，选择下标 `{1,2}`，重量恰好 `50`。接口 [`knapsack01`](./dynamicProgramming.hpp) 返回 `maxValue`、`totalWeight` 和 `itemIndices`。空物品集或容量 `0` 返回空选择；负容量、非正重量或负价值抛出 `std::invalid_argument`。

## 3. 实验二：矩阵乘法链

### 问题背景

需要按固定顺序计算 `A1*A2*...*An`，但可以改变**加括号的位置**。矩阵乘法具有结合律，不同括号方案得到相同结果，却可能需要不同数量的标量乘法。例如 `A1` 是 `10×30`、`A2` 是 `30×5`、`A3` 是 `5×60`：

- `(A1*A2)*A3` 的计算量为 `10·30·5 + 10·5·60 = 4500`。
- `A1*(A2*A3)` 的计算量为 `30·5·60 + 10·30·60 = 27000`。

目标是在**不改变矩阵顺序**的前提下，使标量乘法次数最少。输入维度数组 `p[0..n]`，矩阵 `Ai` 的维度为 `p[i-1]×p[i]`。

### 状态与转移

令 `cost[i][j]` 为从 `Ai` 到 `Aj` 的最小计算量，`cost[i][i]=0`。最后一次乘法必然把区间分为 `[i,k]` 与 `[k+1,j]`，其中 `i ≤ k < j`：

```text
cost[i][j] = min_k { cost[i][k] + cost[k+1][j] + p[i-1]·p[k]·p[j] }
```

先计算长度为 `2` 的区间，再逐步增大区间长度。另存最佳分割点 `split[i][j]`，递归读取它即可输出括号方案。对经典维度 `{30,35,15,5,10,20,25}`，最少需要 `15125` 次标量乘法。接口 [`matrixChainOrder`](./dynamicProgramming.hpp) 返回 `minCost` 和 `parenthesization`；至少要有一个矩阵，所有维度必须为正。这里计算的是**乘法顺序**，没有实际创建或乘出矩阵。计数超出 `long long` 范围时抛出 `std::overflow_error`。

## 4. 实验三：所有顶点对的最短路径（Floyd–Warshall）

### 问题背景

给定带权有向图，想知道**任意起点到任意终点**的最短距离，例如多个仓库之间的最便宜路线。边权可以为负，但图中不能有负权环：如果一条路线能绕负环任意多圈，所谓“最短距离”就没有有限值。

输入是 `V×V` 权重矩阵：`weights[i][j]` 是边 `i→j` 的权值；无边填 `infinity`；对角线填 `0`。实现中 `infinity = LLONG_MAX/4`，有限边权与累计路径权值都要严格位于 `(-infinity, infinity)` 内。

### 状态与转移

令 `D^(k)[i][j]` 表示从 `i` 到 `j` 的路径只允许把编号 `0..k` 的顶点作为**中间顶点**时的最短距离。考虑是否经过新允许的顶点 `k`：

```text
D^(k)[i][j] = min(D^(k-1)[i][j], D^(k-1)[i][k] + D^(k-1)[k][j])
```

初始状态是直接边的权值。代码按 `k`、`i`、`j` 三层循环原地更新距离矩阵；若两段中任意一段不可达，就不进行相加。`next[i][j]` 保存从 `i` 到 `j` 的最短路上离开 `i` 后的第一个顶点。若经 `k` 改善路线，令 `next[i][j]=next[i][k]`，即可逐步恢复路径。

例如 `0→1(4)、0→2(11)、1→2(-2)、2→3(3)、3→1(1)`，从 `0` 到 `3` 的距离为 `5`，路径是 `0→1→2→3`。接口 [`floydWarshall`](./dynamicProgramming.hpp) 返回所有距离和 `next`，接口 [`restoreFloydPath`](./dynamicProgramming.hpp) 返回顶点序列；不可达时返回空序列。算法检测到**图中任何负环**就抛出 `std::invalid_argument`；输入非方阵或对角线不是 `0` 也会被拒绝。

## 5. 实验四：带负权边的单源最短路径（Bellman–Ford）

### 问题背景

给定起点 `s`，只需计算它到各顶点的最短路。折扣、收益等可能表示成负边权，这时不能沿用“取当前最近顶点后就最终确定”的 Dijkstra 论证。Bellman–Ford 容许负边，并能检测**从起点可达**的负环。不可达区域的负环不影响从 `s` 出发的答案。

### 状态与转移

定义 `d_r[v]` 为从 `s` 到 `v`、最多使用 `r` 条边的最短路径长度。初始 `d_0[s]=0`，其余为 `infinity`。每增加一条边，可以保持旧答案，也可以沿某条边 `u→v` 延长：

```text
d_r[v] = min(d_(r-1)[v], min_{u→v}(d_(r-1)[u] + weight(u,v)))
```

没有可达负环时，最短路径可以取成不重复顶点的简单路径，最多有 `V-1` 条边。因此重复扫描全部边 `V-1` 轮即可。代码用一维距离数组**原地松弛**；一轮内可能利用刚更新的值，这只会使答案更早收敛，不会破坏正确性。若完整一轮没有改进便提前结束。最后再扫描一轮：若仍能缩短某个可达顶点的距离，就存在可达负环，抛出 `std::invalid_argument`。

每次改善 `v` 时记录 `parent[v]=u`，从目标沿前驱回溯到起点，再反转。对边 `0→1(4)、0→2(5)、1→2(-2)、2→3(3)`，从 `0` 到 `3` 的距离为 `5`，路径为 `0→1→2→3`。接口 [`bellmanFord`](./dynamicProgramming.hpp) 与 [`restoreBellmanFordPath`](./dynamicProgramming.hpp) 分别负责求解和路径恢复；不可达顶点距离为 `infinity`，路径为空。

与 Floyd–Warshall 相比，本算法仅处理一个起点，适合稀疏图；反复对每个起点调用可求所有点对，但通常要 `O(V²E)` 时间。顶点编号必须位于 `[0,V)`，至少有一个顶点，有限权值与路径和必须落在上述可表示范围。

## 6. 实验五：网组的最大无交叉子集

### 问题背景与模型

在两条平行边界上各有 `n` 个端点，分别从左到右编号 `0..n-1`。每条线连接一个上排端点和一个下排端点，且每个端点恰好用一次。输入 `lowerEndOfUpper[i]` 表示从上排第 `i` 个端点出发的线连接下排哪个位置，因此它必须是 `0..n-1` 的**排列**。目标是选出最多条互不相交的线；线之间若在边界之间相交就称为交叉。

设上排两条线的起点满足 `i<j`。若它们的下排终点满足 `lowerEndOfUpper[i] > lowerEndOfUpper[j]`，两条线的左右顺序颠倒，必然交叉；若下排顺序仍递增则不交叉。因此问题等价于找下排端点序列的**最长严格递增子序列**（LIS）。

### 状态与转移

令 `length[i]` 为**必须选第 `i` 条线作为最后一条**时能选出的最多线数：

```text
length[i] = 1 + max { length[j] | j<i 且 lowerEndOfUpper[j]<lowerEndOfUpper[i] }
如果没有可接在前面的 j，length[i]=1。
最终答案 = max_i length[i]
```

按 `i` 从左到右计算，并保存使状态改进的 `previous[i]`，就能从最佳末端倒推所有上排端点下标。例如排列 `{3,0,2,1,4}`，可选 `{1,2,4}`，其下排终点是 `{0,2,4}`，共 `3` 条。接口 [`maximumNoncrossingNets`](./dynamicProgramming.hpp) 返回 `count` 和 `upperIndices`。空网组返回 `0`；缺失、重复或越界的下排端点会抛出 `std::invalid_argument`。
