# 第 3 章：渐近分析——从代码到时间与空间复杂度

本章建立贯穿整个课程的分析语言。渐近复杂度不是看见两层循环就写 `O(n²)`，而是先定义输入规模与基本操作，再计算执行次数、说明输入情形，最后给出有条件的上界、下界或紧确界。

## 1. 学习目标、先修知识与阅读路线

先修第 1 章的循环不变量和第 2 章的基础排序。学完后应能：

1. 区分输入规模、基本操作、最好／最坏／平均情况。
2. 正确使用 `O`、`Omega`、`Theta`、`o` 和 `omega`。
3. 用求和分析变化边界的循环，用递推或递归树分析递归。
4. 同时报告时间和额外空间，并说明隐藏的对象操作成本。
5. 证明二分查找的区间不变量与对数复杂度。
6. 识别伪多项式、均摊、输出敏感等后续章节会用到的复杂度表述。

先读本讲义并手算表格，再读 [`complexityDemo.cpp`](./complexityDemo.cpp) 观察操作次数，最后读 [`binary.hpp`](./binary.hpp) 和演示中的断言。这里没有独立 `test*.cpp`；[`complexityDemo.cpp`](./complexityDemo.cpp) 既是演示也是本章的可执行核对。

## 2. 第一步：定义输入规模和基本操作

`n` 不是固定含义。它可以是数组长度、结点数、顶点数、容量的数值或输出数量。分析前必须说明：

- 排序：`n` 是元素数，可计键比较和元素移动。
- 图：通常同时有顶点数 `V`、边数 `E`。
- 矩阵：用行数 `r`、列数 `c`，完整扫描是 `Theta(rc)`。
- 背包动态规划：元素数 `n` 与整数容量 `C` 都影响成本，`O(nC)` 对输入位数并非多项式。

下文默认整数比较、加减、数组下标访问和固定大小对象赋值为 `Theta(1)`。若键是长度为 `L` 的字符串，一次比较最坏可能是 `Theta(L)`；若容器复制一整条部分解，也不能当成常数。复杂度应把这些假设写出来。

最好、最坏和平均情况讨论的是**同一规模的不同输入**：

```text
T_best(n)  = 长度为 n 的所有合法输入中最少工作量
T_worst(n) = 长度为 n 的所有合法输入中最多工作量
T_avg(n)   = 在明确概率分布下的期望工作量
```

没有输入分布就不能从几组随机样本宣布“平均复杂度”。

## 3. 渐近记法的严格含义

设 `f(n)`、`g(n)` 从某个规模起非负，且 `g(n)>0`：

| 记法 | 含义 | 定义要点 |
| --- | --- | --- |
| `f(n)=O(g(n))` | 渐近上界 | 存在固定 `c>0,n0`，所有 `n>=n0` 有 `f(n)<=c*g(n)` |
| `f(n)=Omega(g(n))` | 渐近下界 | 存在固定 `c>0,n0`，所有 `n>=n0` 有 `f(n)>=c*g(n)` |
| `f(n)=Theta(g(n))` | 紧确同阶 | 同时属于 `O(g)` 与 `Omega(g)` |
| `f(n)=o(g(n))` | 严格低阶 | `f(n)/g(n)` 趋于 0 |
| `f(n)=omega(g(n))` | 严格高阶 | `f(n)/g(n)` 趋于无穷 |

例如 `f(n)=3n²+7n+4`。当 `n>=1`：

```text
3n² <= f(n) <= 14n²
```

所以 `f(n)=Theta(n²)`。它也属于 `O(n³)`，但后者更松；`Theta(n³)` 则错误。复杂度不是等式意义上的精确运行次数，不能把 `O(n)` 读作“恰好执行 n 次”。

常见增长顺序：

```text
1 < log n < n < n log n < n² < n³ < 2^n < n!
```

对数换底只乘常数，因此固定底数下都写 `Theta(log n)`。这只描述足够大输入；小输入还受常数、缓存和实现质量影响，第 4 章会继续讨论。

## 4. 循环分析：先写次数，再化简

建议固定四步：

1. 标出规模和要计数的语句。
2. 写出每层循环在每次外层迭代中的真实次数。
3. 求和、界定或比较级数。
4. 给出结果，并说明最好／最坏输入条件。

### 4.1 顺序扫描：`Theta(n)`

[`linearVisits`](./complexityDemo.cpp) 对每个位置做一次固定工作：

```text
T(n) = 1 + 1 + ... + 1 = n = Theta(n)
```

若寻找目标并在命中后返回，目标在首位时最好 `Theta(1)`，不存在或在末位时最坏 `Theta(n)`。

### 4.2 三角形循环：`Theta(n²)`

[`triangularPairs`](./complexityDemo.cpp) 第 `i` 轮执行 `i` 次内层工作：

```text
T(n) = 0+1+2+...+(n-1) = n(n-1)/2 = Theta(n²)
```

它没有在每一轮都执行 `n` 次，但总量仍为平方级。枚举所有无序元素对、邻接矩阵上三角等问题都会出现这个和式。

### 4.3 每轮减半：`Theta(log n)`

[`halvingSteps`](./complexityDemo.cpp) 反复令正整数除以 2：

```text
n -> floor(n/2) -> floor(n/4) -> ... -> 1
```

对 `n>=1` 恰有 `floor(log2 n)` 次。判断循环量级不能只看 `while`，要看状态如何接近终止条件。

### 4.4 “外层减半 + 内层循环”有两种答案

若每层仍完整扫描原数组：

```text
n + n + ... + n，共 log n 层 = Theta(n log n)
```

若每层只扫描不断缩小的剩余区间：

```text
n + n/2 + n/4 + ... < 2n = Theta(n)
```

循环形状相似，工作边界不同，答案就不同。这是只数嵌套层数最常见的错误。

## 5. 二分查找：正确性与复杂度来自同一不变量

[`binarySearch`](./binary.hpp) 的前置条件是数组 `a[0..n)` 已按非递减顺序排列。未找到返回 `-1`，重复值可能返回任意匹配位置。

维护闭区间 `[left,right]`，不变量为：

> 若目标 `x` 存在，则至少有一个匹配位置仍在当前区间内。

取 `middle = left + (right-left)/2`：

- `x == a[middle]`：后置条件成立，返回。
- `x > a[middle]`：排序性质证明左半边不可能匹配，令 `left=middle+1`。
- `x < a[middle]`：对称地令 `right=middle-1`。

以 `[0,2,4,6,8,10,12,14]` 查 `13`：

| 轮次 | 区间 | 中点值 | 新区间 |
| ---: | --- | ---: | --- |
| 1 | `[0,7]` | 6 | `[4,7]` |
| 2 | `[4,7]` | 10 | `[6,7]` |
| 3 | `[6,7]` | 12 | `[7,7]` |
| 4 | `[7,7]` | 14 | 空区间 |

每次失败后区间长度至多减半，所以最坏 `Theta(log n)`；第一次命中最好 `Theta(1)`；迭代版本额外空间 `Theta(1)`。`n=0` 时 `right=-1`，循环不进入，可传空指针。

中点写成 `left+(right-left)/2`，避免 `left+right` 在大下标时溢出。若数据原本无序，必须把排序成本也算进“排序后查一次”的总流程；一次查询通常不值得先花 `O(n log n)` 排序。

## 6. 递归：写出递推式和调用栈

把一次调用拆成子问题与本层工作：

| 结构 | 递推式 | 时间 | 常见栈空间 |
| --- | --- | --- | --- |
| 一个半规模子问题 | `T(n)=T(n/2)+Theta(1)` | `Theta(log n)` | `Theta(log n)` |
| 两个半规模子问题，每层线性合并 | `T(n)=2T(n/2)+Theta(n)` | `Theta(n log n)` | `Theta(log n)`，另计辅助数组 |
| 一个规模减 1 子问题 | `T(n)=T(n-1)+Theta(1)` | `Theta(n)` | `Theta(n)` |
| 全排列 | `T(n)=n*T(n-1)+输出成本` | `Theta(n*n!)` 含输出 | `Theta(n)` |

第二行的递归树每层总工作约为 `n`，层数约 `log2 n`。时间递推不能直接告诉全部空间：归并排序除了调用栈还常持有 `Theta(n)` 缓冲区。

## 7. 三类容易被忽略的复杂度

### 7.1 均摊复杂度

动态数组一次扩容会移动 `Theta(n)` 个元素，但容量倍增时，一串 `n` 次尾插总搬移量是几何级数 `1+2+4+...<2n`，所以每次尾插的**均摊**成本是 `O(1)`。均摊不是概率平均；它保证任意操作序列的总成本。

### 7.2 输出敏感复杂度

若算法必须输出 `k` 个结果，时间至少为 `Omega(k)`。枚举排列还要输出每个排列的 `n` 个元素，因此至少 `Omega(n*n!)`。后续凸包、稀疏矩阵等也可能用输入量与输出量共同表达成本。

### 7.3 伪多项式复杂度

背包 `O(nC)` 中，`C` 是容量数值；二进制表示 `C` 只需 `log C` 位。因而该时间对数值看似多项式，对输入编码长度却可能指数增长。称其为伪多项式更准确。

## 8. 空间复杂度和所有权

默认报告**额外空间**，需要说明是否包含返回结果：

- 原地二分查找：除输入外 `Theta(1)`。
- 递归二分：调用栈 `Theta(log n)`。
- 返回长度为 `n` 的新数组：输出本身 `Theta(n)`；若另有同长缓冲，还要再计。
- 宽度优先搜索：队列、访问标记和父数组通常 `Theta(V)`。

容器中保存指针并不等于空间免费：结点对象、分配器开销和指针字段都属于存储。复杂度只隐藏常数，不应在工程比较中忘记它们。

## 9. 常见误区检查表

- 把 `O` 当精确值；能证明紧确界时应写 `Theta`。
- 用最好情况 `Theta(1)` 宣称算法整体是常数时间。
- 只数循环层数，不写内层边界或求和。
- 忽略预处理、复制状态、比较长对象和分配内存。
- 把几次计时曲线当成数学复杂度证明。
- 递归只算时间，不算调用栈。
- 把期望复杂度、均摊复杂度和最坏复杂度混写。
- 写 `O(V+E)` 却实际使用邻接矩阵逐行扫描；表示方式会改变成本。
