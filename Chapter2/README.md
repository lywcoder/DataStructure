# 第二章：排序的核心思想与及时终止

目标：理解每轮排序“保证了什么”，再判断何时可以安全少做工作。以下均按非递减顺序排序。

## 1. 阅读顺序与接口约定

1. 先读本说明，掌握不变式和提前结束的条件。
2. 再读配套 `sortingAlgorithms.hpp`（C++11、`chapter2` 命名空间），运行 `sortingDemo.cpp` 与 `testSortingAlgorithms.cpp`。
3. 最后对照原始 `bubble.hpp`、`selection.hpp`、`insert.hpp`、`rank.hpp`、`rearrage.hpp`，注意第 7 节的区别。

配套教学实现已放在本目录，原有教材示例文件保持不变；验证结果见第 8 节。
`find.hpp` 是查找，`ploy.hpp` 是多项式求值，不属于排序，本说明不修改它们。

统一约定：

- `n >= 0`；`n > 0` 时，数组指针非空且指向至少 `n` 个有效元素。`n == 0` 可传空指针，不应解引用。
- 新模板的键比较仅使用 `<`，不要求元素提供 `>`、`<=`、`>=`、`==`。
- `<` 必须满足严格弱序；“相等键”指 `!(x < y) && !(y < x)`，不一定是对象完全相同。
- 元素还需支持相应的复制、赋值或交换操作；复杂度表将这些操作视为常数时间。
- 插入辅助函数是特例：插入到长度为 `n` 的前缀时，必须有额外的有效可写槽位 `a[n]`；即使 `n == 0` 也不能传空指针。
- 排名数组必须有 `n` 个有效槽位；`rearrange` 的排名必须恰为 `0..n-1` 的一个排列，且不能与数据存储重叠。

新接口速查（均位于 `chapter2`，省略模板声明）：

| 接口 | 含义 |
| --- | --- |
| `isSorted(const T a[], int n)` | 检查所有相邻对，无 `a[i] < a[i-1]` 即有序；空数组也有序 |
| `bubble(T a[], int n)` | **仅一趟**相邻比较，把最大元素送到末尾，不是完整排序 |
| `bubbleWithSwapFlag(T a[], int n)` | 同样一趟；返回 `bool`，发生过交换为 `true` |
| `bubbleSort` / `bubbleSortEarlyExit` | 参数均为 `(T a[], int n)`；基础版／及时终止版 |
| `indexOfMax(const T a[], int n)` | 返回最大元素下标；空数组返回 `-1`，不可拿它索引 |
| `selectionSort` / `selectionSortEarlyExit` | 参数均为 `(T a[], int n)` |
| `insertIntoSortedPrefix(T a[], int n, const T& x)` | 先保存 `x`，再插入已排序前缀，不修改调用者的长度变量 |
| `insertionSort` / `insertionSortEarlyExit` | 参数均为 `(T a[], int n)` |
| `rank(const T a[], int n, int r[])` | 计算每个元素唯一的目标下标，不修改 `a` |
| `rearrange(T a[], int n, const int r[])` | 按排名重排，使用辅助数组，不修改 `r` |
| `rankSort` / `rankSortEarlyExit` | 参数均为 `(T a[], int n)`；封装排名与重排 |

## 2. 冒泡排序：相邻交换，把最大值送到右边

一趟从左到右扫描，若 `a[i+1] < a[i]` 就交换。
例如 `[3, 1, 2] → [1, 3, 2] → [1, 2, 3]`，本趟最大值 `3` 到达末尾。

**不变式：** 一趟扫描到某处时，已扫描部分的最大值位于扫描边界；每完成一趟，右侧已归位后缀增加一个元素。
后续只需处理尚未归位的前缀，因此基础版依次扫描长度 `n, n-1, ..., 2`。

**及时终止：** 用 `bubbleWithSwapFlag` 记录整趟是否交换。返回 `false` 时立即结束外层循环。

为什么正确？整趟无交换意味着每个相邻对都没有逆序，因此整个活动前缀有序；右侧后缀已经归位，两部分合起来也有序。
注意必须完成整趟才能判断；一个相邻对不需要交换，不代表后续也不需要。

只在严格逆序时交换，不会颠倒相等键的先后次序，所以冒泡排序稳定。

## 3. 选择排序：找到最大值，直接放到末尾

每轮在活动前缀中找最大元素，再与前缀末尾交换。
例如 `[2, 3, 1] → [2, 1, 3] → [1, 2, 3]`。

**不变式：** 每轮结束后，右侧后缀已有序、位置最终确定，且前缀中的任何元素都不大于后缀中的元素。
与冒泡不同，找最大值期间不必连续移动它，每轮最多做一次末尾交换。

**及时终止：** 找最大值的同一次扫描中，另行检查所有相邻逆序：

```cpp
if (a[i] < a[i - 1]) sorted = false;
```

`sorted` 每轮先设为 `true`。扫描完成后，若仍为 `true`，必须在末尾交换**之前**退出；否则正常放置最大值。
最大值下标和前缀是否有序是两个不同的信息，不能混淆。

为什么正确？无相邻逆序就证明整个活动前缀有序，再结合已归位后缀的不变式，整个数组已有序。
额外的相邻比较只增加常数开销，无序输入上不保证更快。

**反例：一轮不交换并不足以退出。** `[3, 1, 2, 4]` 的最大值已在末尾，但前缀 `[3, 1, 2]` 仍无序。

选择排序通常不稳定：`[2甲, 2乙, 1]` 若选择第一个最大值并与末尾交换，会成为 `[1, 2乙, 2甲]`。
相等键原来的先后次序被远距离交换打乱。

## 4. 插入排序：把当前元素插进有序前缀

将数组看成“有序前缀 + 尚未处理部分”。从第二个元素起，先保存 `t = a[i]`，将前缀中严格大于 `t` 的元素右移，再填入 `t`。
例如 `[1, 4, 2, 3]`：插入 `2` 后为 `[1, 2, 4, 3]`，再插入 `3` 得 `[1, 2, 3, 4]`。

**不变式：** 第 `i` 轮开始前，`a[0..i-1]` 已排序；插入后，`a[0..i]` 已排序且包含同样的元素。
基础版调用 `insertIntoSortedPrefix(a, i, a[i])`，辅助函数先保存 `x` 再移动元素，且不改变 `i`。
排序内使用的额外槽位就是已有的 `a[i]`，不需要把数组扩容。
辅助函数内部的值副本也保证了安全性：即使 `x` 引用数组内的元素，右移也不会覆盖待插入的值。

**提前跳过本轮：** 若 `!(a[i] < a[i-1])`，当前元素已不小于前缀最大值，直接 `continue`。
这个检查应放在复制 `t` **之前**，以避免无用的复制和回写。
否则保存 `t` 并右移；内层遇到 `!(t < a[j])` 就停止，不能再越过更小或等价的元素。
基础版本来就有这个内层停止条件，因此优化主要减少不必插入时的对象复制，不改变渐近复杂度。

**不能因为本轮没有移动就结束整个外层循环。** `[1, 2, 4, 3]` 中插入 `2` 或 `4` 都不用移动，但末尾的 `3` 仍要处理。
已排序的只是前缀，未扫描的后缀没有任何有序保证。

只右移严格大于 `t` 的元素，插入时不越过相等键，因此两版都稳定。

## 5. 排名排序：先决定每个元素去哪里，再重排

这里的 rank sort / count sort 是**逐对比较的排名排序**，不是按整数值建立直方图、耗时 `O(n+k)` 的经典计数排序。

先将所有 `r[i]` 置零，然后对每一对 `j < i`：

```cpp
if (!(a[i] < a[j])) ++r[i];
else ++r[j];
```

每对元素中，较大的那个增加排名；键等价时，原位置靠后的 `i` 增加排名。
因此 `r[i]` 等于“严格更小的元素数 + 前面相等键的元素数”。
例如 `[2甲, 1, 2乙]` 得排名 `[1, 0, 2]`，重排为 `[1, 2甲, 2乙]`。

**不变式：** 已处理的每一对都恰好为排序位置较后的元素贡献一次计数；全部完成后，排名唯一且覆盖 `0..n-1`。
可理解为按“键值优先、原始位置打破平局”的顺序排序，所以不会有两个元素写到同一目标位置。

新 `rearrange` 使用 `std::vector<T>` 复制原数组，再执行 `u[r[i]] = a[i]`，最后写回。
先复制而不是创建 `n` 个默认元素，可避免要求 `T` 支持默认构造；空数组路径也不应对空指针做偏移。
排名向量与元素缓冲合计仍为 `O(n)` 额外空间，`r` 不变，最终排序稳定。

**及时终止：** `rankSortEarlyExit` 先做一次全局 `isSorted` 检查；已排序就直接返回，否则执行完整排名和重排。
这有完整数组的有序性证明，不能把“部分元素对已处理”当作提前结束的依据。
基础排名固定比较 `n(n-1)/2` 对；有序输入上的预检查把最佳时间降为线性，无序时只额外增加线性检查。

### 原始 `rearrage.hpp`：另一种原地重排

原始版本在 `r[i] != i` 时取 `t = r[i]`，同时交换 `a[i]` 与 `a[t]`、`r[i]` 与 `r[t]`。
元素与自己的目标排名一起移动，沿置换环逐步归位；每次交换至少让一个位置归位，故重排为 `O(n)` 时间。
完成后 `r[i] == i`，原始排名被改写。
此重排步骤额外空间为 `O(1)`，但完整排名排序仍需要 `O(n)` 的排名数组。
只要排名按上述规则唯一并处理平局，最终结果仍稳定；交换本身不自动意味着最终结果不稳定。
它是原始实现的对照，不是新 `rearrange` 接口的行为。

## 6. 复杂度与稳定性对照

下表针对一般规模的输入；`n = 0/1` 都可直接结束。空间不计输入数组，计入排名和重排缓冲。

| 算法 | 基础版最好 / 最坏 | 及时终止版最好 / 最坏 | 额外空间 | 稳定 |
| --- | --- | --- | --- | --- |
| 冒泡排序 | `Θ(n²)` / `Θ(n²)` | `Θ(n)` / `Θ(n²)` | `O(1)` | 是 |
| 选择排序 | `Θ(n²)` / `Θ(n²)` | `Θ(n)` / `Θ(n²)` | `O(1)` | 否 |
| 插入排序 | `Θ(n)` / `Θ(n²)` | `Θ(n)` / `Θ(n²)` | `O(1)` | 是 |
| 排名排序（辅助数组版） | `Θ(n²)` / `Θ(n²)` | `Θ(n)` / `Θ(n²)` | `O(n)` | 是，需上述平局规则 |

排名及时终止版若在分配前检查有序性，已排序路径可以只用 `O(1)` 额外空间；表中列的是一般路径的空间上界。
“及时终止”不是统一的 `break`：冒泡和选择可结束剩余轮次，插入只跳过本轮或停止内层，排名则靠排序前的全局检查。

## 7. 对照原代码时的注意事项

- `insert.hpp` 同时定义 `insert(T[], int&, const T&)` 与 `insert(T[], int, const T&)`。
  `insert(a, i, t)` 对左值 `i` 会产生重载歧义；若仅保留引用版，它的 `n++` 还会意外改变外层循环的 `i`，跳过待处理元素。
  新辅助函数独立命名，并按值接收长度，避免这两个问题。
- `bubble.hpp` 的注释版 `bool bubble(...)` 不能与原 `void bubble(...)` 仅凭返回类型重载；新接口改名为 `bubbleWithSwapFlag`。
  注释中的 `for (int i = n; i > 1 && bubble(a, i), i--);` 缺少第二个分号，逗号也不是条件与递减部分的分隔符。
- 原头文件使用未限定的 `swap`，且缺少自包含的相应头文件；直接单独包含时不保证可编译。新实现应包含所需标准头并使用合适的 `std::swap`。
- 原 `rank.hpp` 与 `rearrage.hpp` 定义了相同签名的 `rearrange`，不能直接放进同一翻译单元；它们分别是辅助数组与原地版本，应作为替代方案阅读。
- 原 `selection.hpp` 的 `indexOfMax` 对空数组返回 `0`，没有实际最大元素，不能据此访问；新接口对空数组返回 `-1`。
- 原选择排序的注释版用“当前最大值与新元素”的比较间接判序；新版本显式检查相邻逆序，并在确认有序后、交换之前退出，证明更直接。
- 原 `rank.hpp` 使用 `<=` 和 `new T[n]`，后者要求默认构造；新接口只比较 `<`，重排缓冲由原元素复制构造。

这些是阅读提示，不表示原始文件已被修复；不要把注释版取消注释后直接与基础版混用。

## 8. 编译与验证

安装 `g++` 后，在 `Chapter2` 目录分别编译、运行；两个源文件应各自生成可执行程序，不要合并链接：

```sh
g++ -std=c++11 -Wall -Wextra -Wpedantic -Werror sortingDemo.cpp -o sortingDemo.exe
./sortingDemo.exe
g++ -std=c++11 -Wall -Wextra -Wpedantic -Werror testSortingAlgorithms.cpp -o testSortingAlgorithms.exe
./testSortingAlgorithms.exe
```

演示和测试已使用上述 C++11 严格警告选项编译运行通过，编辑器诊断无错误或警告。测试对八个版本分别验证了 3,280 个穷举输入和 200 个随机输入，覆盖以下项目：

- 将各排序结果与 `std::sort` 对照；对稳定算法用带原始序号的对象与 `std::stable_sort` 对照，比较器只比较键。
- 穷举小长度、小取值范围数组，并用固定随机种子生成更多数组，便于重现失败。
- 覆盖空数组（含空指针）、单元素、有序、逆序、全相等、重复键，以及上述两个不能提前退出的反例。
- 单测辅助函数：一趟冒泡只保证最大值到末尾、交换标志、空数组最大值下标、插入槽位及长度不变、排名唯一且重排不改排名。
- 使用只定义 `<`、不支持默认构造的可复制对象，检查新接口的类型要求与承诺一致。
- 统计 `<` 的调用次数：有序输入时，冒泡、选择、排名的及时终止版应为 `O(n)`；基础冒泡、选择、排名仍为 `Θ(n²)`。
- 插入两版有序时本就线性；另计复制和赋值次数，验证提前跳过本轮后不发生元素复制或回写。

32 个已有序元素的实际比较次数：

| 算法 | 基础版 | 及时终止版 |
| --- | --- | --- |
| 冒泡 | 496 | 31 |
| 选择 | 496 | 62 |
| 插入 | 31 | 31 |
| 排名 | 496 | 31 |

选择优化版同时比较“当前最大值”和“相邻逆序”，所以一次扫描有两组比较；仍然是线性级别。及时终止不保证在所有输入上都更快。
