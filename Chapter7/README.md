# 第 7 章：数组、矩阵与稀疏矩阵

本章围绕一个问题展开：**矩阵在数学上有 `行 × 列` 个位置，但在内存里需要保存哪些值？**普通矩阵保存全部位置；有固定形状的特殊矩阵只保存可能非零的位置；稀疏矩阵只保存实际非零的项。建议先读普通矩阵与下标映射，再读特殊矩阵，最后重点推演两种稀疏表示和快速转置。

## 1. 矩阵抽象数据类型（ADT）

一个 `r × c` 矩阵有 `r` 行、`c` 列。`matrixADT.hpp` 只规定 `rows()`、`columns()`、`get(i,j)`、`set(i,j,value)`，不规定底层是否保存所有元素。`matrix<T>`、三种特殊矩阵和两种稀疏矩阵都实现这个接口，因此可以用同一套坐标概念比较它们。

**统一约定：** 公开接口使用数学教材常见的 **1 起始下标**，即 `1 ≤ i ≤ r`、`1 ≤ j ≤ c`；C++ 数组和 `std::vector` 内部仍使用 0 起始下标。`0×0` 是合法空矩阵；一个维度为 0、另一个为正数的形状被拒绝。越界抛 `std::out_of_range`，非法形状或不相容的运算抛 `std::invalid_argument`。代码以 `T{}` 表示零，因此这些实现面向具有零值、复制以及相应算术运算的元素类型。

`std::vector` 是**连续存储的动态数组**。本章用它实现单个数组、每行一个数组和压缩矩阵的存储；它会管理元素生命期与复制，便于把注意力放在坐标到数组下标的映射上。第 5 章的 `arrayList` 是手写动态数组的教学实现，概念相同，但其虚函数对三元组元素有额外比较和输出要求。

## 2. 普通矩阵：一个行优先数组

`matrix.hpp` 的 `matrix<T>` 把全部 `r×c` 个元素放在一个连续数组里。行优先（row-major）顺序是先存完整的第 1 行，再存第 2 行：

```text
矩阵       1  2  3       内部数组：1  2  3  4  5  6
           4  5  6

公开坐标 (i,j) → 内部下标 (i-1)*c + (j-1)
例如 2×3 的 (2,2) → (2-1)*3+(2-1) = 4，即数组中的 5。
```

知道坐标时能直接算下标，所以 `get`、`set` 是 `Θ(1)`。`matrix<T>` 实现转置、逐项加减、取负、标量相加与矩阵乘法；赋值和复制由 `std::vector` 负责，不会共享存储。若 A 为 `r×k`，B 为 `k×c`，乘积 C 为 `r×c`，且 `C(i,j)=Σ A(i,t)B(t,j)`，朴素乘法用三层循环，需要 `Θ(rkc)` 时间。

| 操作 | 时间 | 结果额外空间 |
| --- | --- | --- |
| 读写一个位置 | `Θ(1)` | `Θ(1)` |
| 转置 | `Θ(rc)` | `Θ(rc)` |
| 相同形状的加减 | `Θ(rc)` | `Θ(rc)` |
| `r×k` 乘 `k×c` | `Θ(rkc)` | `Θ(rc)` |

结果矩阵的存储算在表中；不计输入。`irregular.cpp` 展示的是另一种数组：每行长度可以不同的“不规则二维数组”。它适合表示每行项数不等的数据，但**不是**具有固定列数的数学矩阵；示例用 `std::vector<std::vector<int>>` 避免手动 `new[]` 后忘记释放。

## 3. 特殊矩阵：利用已知形状压缩

以下均为 `n×n` 方阵。其 `get(i,j)` 仍表现得像普通矩阵，只是内部只保存必要值。对按结构必须为零的位置，`set(i,j,0)` 可以接受；写非零值会抛 `std::invalid_argument`。这不是忽略用户写入，而是在维护矩阵所属的特殊类别。

| 类 | 必须保存的元素 | 存储量 | 内部映射，`i,j` 从 1 开始 |
| --- | --- | --- | --- |
| `diagonalMatrix` | 仅 `i=j` | `n` | 对角项 `(i,i) → i-1` |
| `tridiagonalMatrix` | `|i-j|≤1` | `3n-2`，`n≥1` | 依次放下、主、上三条对角线 |
| `symmetricMatrix` | `a(i,j)=a(j,i)` | `n(n+1)/2` | 仅存下三角；上三角映射到 `(j,i)` |

### 对角矩阵

```text
[d1  0  0]
[ 0 d2  0]  → [d1, d2, d3]
[ 0  0 d3]
```

`diagonal.hpp` 的数组只有 `n` 个值。读非对角位置直接返回零；不需要为那些零分配空间。

### 三对角矩阵

```text
[a1 b1  0  0]
[c1 a2 b2  0]
[ 0 c2 a3 b3]
[ 0  0 c3 a4]

内部：[c1,c2,c3 | a1,a2,a3,a4 | b1,b2,b3]
```

`tridiagonal.hpp` 用一个数组按“下对角、主对角、上对角”排列。`n≥1` 时，下对角 `(i,i-1)` 的下标是 `i-2`；主对角 `(i,i)` 是 `n+i-2`；上对角 `(i,i+1)` 是 `2n+i-2`。例如 `n=4` 时一共 `3+4+3=10` 个槽位，远少于稠密数组的 16 个。`n=0` 时数组为空。

### 对称矩阵

```text
[a11 a21 a31]
[a21 a22 a32]  → 只存：a11 | a21,a22 | a31,a32,a33
[a31 a32 a33]
```

`symmetric.hpp` 按行存下三角。若 `i<j`，先交换 `i,j`；随后数组下标是 `i(i-1)/2+(j-1)`。因此 `set(1,3,x)` 与 `set(3,1,x)` 写的是同一个槽位，两处读取自然相等。它能表示**任意**对称矩阵；与对角、三对角不同，不会限制某个非对角位置必须为零。

## 4. 稀疏矩阵：只保存真正的非零项

若一个 `r×c` 矩阵大部分位置为零，保存全部 `rc` 个值浪费空间。令 `t=nnz` 表示非零项数。例如 `1000×1000` 的矩阵只有 8 个非零项时，稠密表示仍保存 100 万个值，而稀疏表示只保存这 8 项及其坐标、索引信息。

本章两种稀疏表示都保持以下**不变量**：

1. 只保存与 `T{}` 不相等的值，显式写零会删除已有项。
2. 一个坐标至多有一个项；再次 `set` 同坐标是更新。
3. 项按行、列排序，这使查找、加法、转置和输出可预测。

压缩存储也有代价：每个非零项还要保存行列编号或列编号。若 `t` 接近 `rc`，稠密数组通常更简单，也可能更省空间、更快。

## 5. 单个线性表：按行列排序的三元组

`sparse.hpp` 的 `sparseMatrix<T>` 使用一个 `std::vector<matrixTerm<T>>`。每个 `matrixTerm` 保存 `(row,col,value)`，整个数组严格按 `(row,col)` 升序：

```text
3×4 矩阵：
[0  0  0  7]
[-3 0  0  0]
[0  5  0  0]

三元组数组：[(1,4,7), (2,1,-3), (3,2,5)]
```

`get(i,j)` 在有序三元组中二分查找：找到返回值，否则返回零，耗时 `O(log(t+1))`。`set(i,j,v)` 也先找位置；若要新增或删除，数组元素可能整体移动，最坏 `O(t)`。`fromDense` 扫描全部 `rc` 个位置来构造三元组；`toDense` 创建并填充完整的 `rc` 个槽位。

### 加法：两个有序序列做归并

对形状相同的 A、B，分别指向两组排序三元组的当前位置。较小坐标直接复制到结果；相同坐标将值相加，若抵消为零则不写入。每个三元组至多处理一次，时间 `O(t_A+t_B)`，结果空间最多 `O(t_A+t_B)`。如果用 `set` 每次在结果数组中插入，反而可能因为反复移动而接近平方时间；直接尾插才体现了已排序的优势。

### 快速转置：列计数、前缀起点、一次定位

转置使旧坐标 `(i,j)` 变为新坐标 `(j,i)`。简单地逐项调用 `set` 会反复搜索和移动。`transpose()` 改用三个步骤：

1. **统计旧列：** `count[j]` 是原矩阵第 `j` 列的非零项数，也就是转置后第 `j` 行的项数。
2. **计算起点：** `start[1]=0`；以后每列的起点等于前一列起点加前一列项数。这样知道每个新行在结果数组中的第一格。
3. **直接写入：** 扫描原有序三元组。旧列 `j` 的项写在 `start[j]`，然后 `start[j]++`，为同列的下一项留位置。

以上面的 `3×4` 矩阵为例，旧列的项数是 `[1,1,0,1]`，结果各新行的起始数组下标是 `[0,1,2,2]`：

| 原项 | 转置后 | 写入结果位置 |
| --- | --- | --- |
| `(1,4,7)` | `(4,1,7)` | 2 |
| `(2,1,-3)` | `(1,2,-3)` | 0 |
| `(3,2,5)` | `(2,3,5)` | 1 |

最终结果数组按新 `(row,col)` 排序为 `[(1,2,-3),(2,3,5),(4,1,7)]`。为什么同一新行内部也有序？原三元组按旧行递增扫描，旧行变成新列，因此它们依次到达。时间 `O(t+c)`，辅助计数数组 `O(c)`，结果本身 `O(t)`。

## 6. 多个线性表：每行一个有序数组

`rowSparse.hpp` 的 `rowSparseMatrix<T>` 使用一个外层数组，长度为行数 `r`；第 `i` 个位置保存该行自己的 `std::vector<rowEntry<T>>`。每个 `rowEntry` 只需 `(col,value)`，因为行号已经由外层位置给出：

```text
rows[1] → [(4,7)]
rows[2] → [(1,-3)]
rows[3] → [(2,5)]
```

各行内部按列升序。若第 `i` 行有 `t_i` 项，`get(i,j)` 只在这一行二分查找，时间 `O(log(t_i+1))`；`set` 新增或删除时只移动该行的项，最坏 `O(t_i)`。空间为 `O(r+t)`，其中 `r` 个行容器即使空行也存在。它可以与单表表示相互转换，也能转回稠密矩阵。

**按行加法：** 对每一行分别归并两个已排序列表，时间 `O(r+t_A+t_B)`。**转置：** 扫描旧行 `1..r`，旧列 `j` 的项直接尾插到结果第 `j` 行，列号改成旧行号；因为旧行按递增顺序扫描，新行中的列号天然有序，时间 `O(r+c+t)`。

### 稀疏乘法：只沿非零路径计算

对 A 的第 `i` 行，遇到非零 `a(i,k)`，只遍历 B 的第 `k` 行。例如 `a(1,2)=3`，而 B 第 2 行有 `(1,4)` 与 `(3,5)`，那么只向结果的 `(1,1)` 加 `12`、向 `(1,3)` 加 `15`。完全不需要访问 A 中大量隐含的零。

实现用长度为结果列数的临时数组 `sums` 累计当前结果行，并用 `touched` 记录真正碰过的列。一个位置可能经多个 `k` 累加；若正负抵消为零，最后仍不保存它。处理完一行后对 `touched` 列号排序，按升序写入该行的结果列表，清除标记后处理下一行。这样维持“每行按列有序”的不变量。

令 `P = Σ_{a(i,k)≠0} nnz(B 的第 k 行)`，即实际访问的非零乘积数量；令 `q_i` 是结果第 `i` 行触及的不同列数。乘法时间为 `O(c_B + P + Σ q_i log q_i + r_A)`，辅助工作数组为 `O(c_B)`，另需结果非零项的空间。这个上界依赖稀疏结构；不能只用 `nnz(A)×nnz(B)` 或盲目宣称 `O(t)`。

## 7. 何时选择哪种表示？

| 表示 | 存储量 | 单点读取 | 单点插入/删除 | 适合情况 |
| --- | --- | --- | --- | --- |
| 稠密行优先数组 | `Θ(rc)` | `Θ(1)` | `Θ(1)` 覆写已有槽位 | 大部分位置有值；频繁随机访问 |
| 单表三元组 | `Θ(t)` | `O(log(t+1))` | 最坏 `O(t)` | 非零项少；需要整体按坐标遍历、归并或快速转置 |
| 每行一个有序表 | `Θ(r+t)` | 第 `i` 行 `O(log(t_i+1))` | 最坏 `O(t_i)` | 经常按行访问、按行相加或稀疏乘法 |

特殊矩阵则应优先利用**已知形状**，因为它们甚至不需要逐项保存行列坐标。无论选择哪种表示，先明确不变量和操作习惯，再看内存和时间成本。

## 8. 原代码中的问题与新版约定

原 `matrix.hpp` 在正常尺寸下没有给成员正确赋值，`rows()` 返回列数，赋值、加法和乘法也存在指针或游标错误。原 `diagonal.hpp` 依赖未定义的异常类，且没有自包含头文件。原 `sparse.hpp` 以交互式提示读入、反复删除旧项，转置时把项插入不对应的位置，也没有系统地维护三元组的排序和唯一性。本章统一改用标准异常、数组容器、清晰的 1 起始坐标约定及可独立包含的头文件。

## 9. 文件与运行方式

| 文件 | 内容 |
| --- | --- |
| `matrixADT.hpp`、`matrix.hpp` | 抽象接口、稠密行优先矩阵及基本运算 |
| `diagonal.hpp`、`tridiagonal.hpp`、`symmetric.hpp` | 三种压缩存储 |
| `sparse.hpp` | 单个有序三元组数组、归并加法、快速转置 |
| `rowSparse.hpp` | 多个按行有序数组、加法、转置、稀疏乘法 |
| `irregular.cpp` | 与规则矩阵不同的不规则二维数组示例 |
| `chapter7Demo.cpp`、`testChapter7.cpp` | 演示与正确性测试 |

在 `Chapter7` 目录分别编译各个带 `main` 的源文件：

```powershell
g++ -std=c++11 -O2 -Wall -Wextra -Wpedantic -Werror chapter7Demo.cpp -o chapter7Demo.exe
.\chapter7Demo.exe
g++ -std=c++11 -O2 -Wall -Wextra -Wpedantic -Werror testChapter7.cpp -o testChapter7.exe
.\testChapter7.exe
g++ -std=c++11 -O2 -Wall -Wextra -Wpedantic -Werror irregular.cpp -o irregularDemo.exe
.\irregularDemo.exe
```

测试通过时没有输出。测试使用 `assert`，不要加入 `-DNDEBUG`；包括基本形状和异常、压缩映射、零值删除、三元组顺序、转置、加法与 150 组随机矩阵的稀疏乘法对照。目录中原有的 `irregular.exe` 是旧构建产物，运行新版示例请使用 `irregularDemo.exe`。
