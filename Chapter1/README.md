# 第 1 章：C++ 算法基础、递归与排列

本章不是零散语法练习，而是后续 20 章共同使用的“算法阅读方法”入门：先写清输入与输出，再找循环或递归不变量，最后分析边界、正确性和复杂度。代码用求和、乘积、货币类、递归排列和字典序下一排列展示值语义、泛型算法、递归回溯和局部变换。

## 1. 学习目标与先修知识

开始前需要会定义函数、数组、类、引用和基本模板。学完后应能：

1. 区分“问题规格”“算法”和“C++ 实现”，给函数写出前置条件与后置条件。
2. 解释模板的类型要求，例如求和需要零值与加法，排列需要可交换元素。
3. 用“选择—递归—撤销”推演全排列，并说明为何不会漏解。
4. 从右向左推导 `next_permutation` 的枢轴、后继和后缀反转。
5. 为一个小类建立表示不变量，处理符号、进位、借位、溢出与异常安全。
6. 使用断言测试正常输入、空输入、重复值和极端数值。

推荐阅读顺序：

1. [`accumulate.hpp`](./accumulate.hpp) 与 [`testChapter1.cpp`](./testChapter1.cpp)：最小的泛型算法。
2. [`perm.hpp`](./perm.hpp)：递归生成所有位置排列。
3. [`nextPermutation.hpp`](./nextPermutation.hpp) 与专题讲义 [`nextPermutation.md`](./nextPermutation.md)：字典序下一排列。
4. [`currency/currency.h`](./currency/currency.h)、[`currency/currency.cpp`](./currency/currency.cpp) 与 [`testCurrency.cpp`](./testCurrency.cpp)：类不变量和算术边界。

## 2. 从规格开始：函数究竟承诺什么

以下函数都叫“算法”，但规格不同：

| 函数 | 输入 | 输出或副作用 | 关键前置条件 |
| --- | --- | --- | --- |
| `sum(a,n)` | `n` 个元素 | 返回总和 | `n >= 0`；类型可由 `0` 构造并支持 `+` |
| `product(a,n)` | `n` 个元素 | 返回乘积 | 类型可由 `1` 构造并支持乘法 |
| `permutations(list,k,m)` | 数组和待定区间 | 输出每一种位置排列 | `0 <= k <= m`，区间有效 |
| `chapter1::next_permutation(first,last)` | 双向迭代器区间 | 原地变为下一排列并返回是否存在 | 元素可比较、可交换 |
| `currency::add(x)` | 两个合法货币值 | 返回代数和，不改两个操作数 | 美分在 `0..99`，金额未溢出 |

规格决定测试。若 `next_permutation` 的当前排列已经最大，它不仅返回 `false`，还要恢复为最小排列；只检查返回值会漏掉一半契约。若 `increment` 声明返回 `currency&`，测试还应确认返回的是原对象本身。

后续各章也应先问四个问题：

- 输入的有效范围是什么？
- 输出代表什么，失败如何表示？
- 哪些对象被修改，哪些保持不变？
- 复杂度以什么规模和基本操作计数？

## 3. 泛型累加：模板不是“任意类型”

[`accumulate.hpp`](./accumulate.hpp) 的两个函数调用标准库 `std::accumulate`：

```cpp
template<class T>
T sum(const T a[], int n) {
    T initial = 0;
    return std::accumulate(a, a + n, initial);
}
```

循环不变量可以写成：处理完前 `i` 个元素后，累加器等于 `a[0] + ... + a[i-1]`。初始 `i=0` 时是加法单位元；每步加入一个元素保持不变量；结束时 `i=n`，得到整个区间的和。

对 `[2,3,4]`：

| 已处理元素数 | 累加器 |
| ---: | ---: |
| 0 | 0 |
| 1 | 2 |
| 2 | 5 |
| 3 | 9 |

时间为 `Theta(n)`，标准算法只保存迭代器和累加器，额外空间为 `Theta(1)`。这里把一次 `T` 的加法与赋值看作常数；若 `T` 是不断增长的大整数或字符串，还应计入对象操作成本。

空区间的和返回 `0`，积返回 `1`，因为它们分别是加法和乘法单位元。这不是随意默认值，而是保证“把两个相邻区间的结果合并”仍成立的代数选择。

## 4. 递归全排列：选择、深入、撤销

[`perm.hpp`](./perm.hpp) 把 `list[0..k-1]` 看成已经固定的前缀，把 `list[k..m]` 看成仍待安排的元素。第 `k` 层依次把每个候选元素交换到位置 `k`，递归安排余下位置，回来后再交换复原。

```text
permutations(list, k, m):
    if k == m: 输出一个完整排列
    else:
        for i = k..m:
            swap(list[k], list[i])   // 作选择
            permutations(list,k+1,m)
            swap(list[k], list[i])   // 撤销选择
```

以 `[A,B,C]` 为例：

```text
固定 A ── 固定 B ── ABC
       └─ 固定 C ── ACB
固定 B ── 固定 A ── BAC
       └─ 固定 C ── BCA
固定 C ── 固定 B ── CBA
       └─ 固定 A ── CAB
```

### 为什么不会漏，也不会重复位置方案

在第 `k` 层，每个尚未使用的数组位置恰好有一次机会成为第 `k` 个位置。选定后，递归假设保证后缀的所有位置排列都被生成；不同分支的第 `k` 个位置来源不同，因此位置方案不相交。对剩余位置数作归纳即可证明覆盖全部 `n!` 个位置排列。

第二次交换是回溯的核心。没有它，下一轮会在上一个分支留下的数组上继续，父层“进入每个分支时后缀元素集合相同”的不变量失效。

若元素值有重复，例如 `[1,1,2]`，位置排列仍有 `3!` 个叶子，但输出文本会重复。若要求只输出不同值排列，可以排序后在同一递归层跳过等价值，或使用字典序下一排列。

生成 `n!` 个长度为 `n` 的输出，光写出结果就需 `Theta(n*n!)` 时间；递归深度为 `n`，除输出外额外空间为 `Theta(n)`。任何声称“生成所有排列只需 `O(n!)`”的说法都隐含把输出一个排列当作常数。

## 5. 字典序下一排列：只做最小幅度的增大

把排列按字典顺序排列。对 `[1,2,4,3]`，下一排列是 `[1,3,2,4]`。目标不是任意找一个更大的排列，而是找**严格大于当前排列的最小者**。

[`nextPermutation.hpp`](./nextPermutation.hpp) 分三步：

1. 从右向左找最右的 `pivot`，满足 `a[pivot] < a[pivot+1]`。
2. 在右侧后缀中找最右的、严格大于枢轴的元素，作为 `successor`，交换二者。
3. 反转枢轴右侧的后缀，让它变成可取得的最小顺序。

### 完整推演：`[1,2,4,3]`

```text
从右向左：4 >= 3，继续；2 < 4，因此 pivot 是 2
后缀 [4,3] 非递增；从右找第一个 > 2 的元素，得到 3
交换： [1,3,4,2]
反转后缀： [1,3,2,4]
```

### 三个关键证明点

- 枢轴右侧原本是非递增序列。否则在更靠右处还能找到上升相邻对，当前枢轴就不是“最右”。
- 从右边找到的第一个较大元素，是后缀中能替换枢轴的最小较大值。这样前缀增加得最少。
- 交换后把后缀变为最小排列，得到固定新前缀下的最小整体排列。

若整个区间都是非递增，例如 `[3,2,1]`，当前已经是最大排列。算法反转为 `[1,2,3]` 并返回 `false`。重复值也正确，因为比较条件使用严格小于；从 `[1,1,2]` 开始只产生 3 个不同排列。

一次调用最多线性扫描和一次反转，时间 `O(n)`、额外空间 `O(1)`。从最小排列枚举全部不同排列时，总时间还要乘以排列数量。

更细的边界、比较器版本和常见错误见 [`nextPermutation.md`](./nextPermutation.md)。

## 6. `currency`：用表示不变量约束一个类

[`currency/currency.h`](./currency/currency.h) 把金额保存为：

```text
sign ∈ {plus, minus}
dollars >= 0
0 <= cents <= 99
零统一表示为 +$0.00
```

这四条是**表示不变量**。构造、两个 `setValue`、`add` 和 `increment` 返回时都必须满足它。把符号与绝对值分开保存，教学上能清楚展示进位和借位；生产金融代码通常更适合直接保存“最小货币单位的有符号整数”，并明确币种和舍入策略。

### 同号相加

`+$3.75 + +$2.50`：美元先得 5，美分得 125；进 1 美元并保留 25 美分，结果 `+$6.25`。负数同号相加只保留负号：`-$1.80 + -$2.25 = -$4.05`。

在加美元前先检查 `ULONG_MAX - dollars`，美分进位前再检查一次。若溢出，抛出 `std::overflow_error`，原对象不变。

### 异号相加就是绝对值相减

比较 `(dollars,cents)` 的字典序即可比较绝对值。用较大绝对值减较小绝对值，并保留较大者符号：

```text
+$3.50 + -$2.25 = +$1.25
+$1.05 + -$2.25 = -$1.20
-$3.10 + +$3.50 = +$0.40
```

当大金额的美分小于小金额的美分时，从美元借 1：`$3.10 - $2.75` 变为 `2 美元 + 110 美分 - 2 美元 - 75 美分 = $0.35`。绝对值比较保证需要借位时美元一定大于 0。

### `increment` 与异常安全

`increment(x)` 先调用 `add(x)` 得到完整临时结果，再赋给自身。这样既支持 `value.increment(value)`，又保证溢出异常发生时原金额没有被改到一半。返回 `*this` 允许链式调用。

`setValue(double)` 拒绝 NaN、无穷和超范围值，并舍入到最近美分，精确半美分按绝对值远离零。二进制浮点通常不能精确表示十进制金额，因此它只用于说明输入转换；要求财务精确性时应从整数美分或十进制文本解析。

所有这些边界由 [`testCurrency.cpp`](./testCurrency.cpp) 覆盖，包括异号、进借位、负零归一、半美分、溢出后对象不变及输出格式。

## 7. 正确性、复杂度与易错点

| 算法 | 正确性抓手 | 时间 | 额外空间 |
| --- | --- | --- | --- |
| 求和／乘积 | 已处理前缀的累积值 | `Theta(n)` | `Theta(1)` |
| 递归全排列 | 固定前缀 + 回溯恢复 | `Theta(n*n!)` 含输出 | `Theta(n)` 栈 |
| 下一排列 | 最右枢轴 + 最小增量 + 最小后缀 | `O(n)` | `O(1)` |
| 货币加法 | 表示不变量、同号进位／异号借位 | `O(1)` | `O(1)` |

常见错误：

- 模板中漏写 `std::`，让代码依赖调用者偶然使用的 `using namespace std`。
- 递归返回后不撤销交换，导致兄弟分支起点错误。
- 把 `next_permutation` 的后缀重新排序成 `O(n log n)`；后缀已有非递增性质，反转即可。
- 只相加货币绝对值再保留左操作数符号，异号时必错。
- 用 `double dollars` 长期保存金额，忽略十进制舍入契约。
- 用 `assert` 检查用户输入；断言用于程序内部不变量，发布构建可能关闭，输入错误应抛异常或返回失败。
