# 数据结构学习代码

本仓库按 `ChapterN/` 组织 C++ 数据结构与算法课程。每章的讲义、实现、演示和测试尽量放在同一目录；从下面的章节入口阅读具体定义、图解、复杂度分析与编译命令。

## 阅读与运行

建议按章节顺序阅读；每章 README 给出与该章代码对应的编译、运行命令。仓库没有统一构建系统，测试通常是使用 `assert` 的独立 C++11 程序。例如从仓库根目录运行第 15 章的 B 树测试：

```powershell
g++ -std=c++11 -O2 -Wall -Wextra -Wpedantic -Werror Chapter15/testBTree.cpp -o Chapter15/testBTree.exe
.\Chapter15\testBTree.exe
```

编译测试时不要使用 `-DNDEBUG`，否则断言不会执行。
