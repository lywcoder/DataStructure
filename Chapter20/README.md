# 第 20 章：回溯法——在解空间树中寻找最优解

回溯法（backtracking）按一定顺序构造候选解：**做选择、深入下一层、撤销选择**。本章用 0/1 背包、最大完备子图、旅行商问题和电路板排列，学习怎样定义搜索树，怎样识别不可能产生更好答案的分支，以及怎样把递归状态写成 C++11 代码。可运行实现在 [`backtracking.hpp`](./backtracking.hpp)，演示和测试分别在 [`chapter20Demo.cpp`](./chapter20Demo.cpp)、[`testChapter20.cpp`](./testChapter20.cpp)。

### 学习目标与先修知识

先修递归、图、动态规划与最优化建模。学完后应能：

1. 区分子集树与排列树，估计叶子数和递归深度。
2. 把可变状态分为当前路径、访问标记、累计目标与辅助统计。
3. 为最大化构造安全上界、为最小化构造安全下界。
4. 逐项证明 `apply` 与 `undo` 互逆，兄弟分支不会共享污染状态。
5. 区分部分可行解与必须完整后才可评价的方案。
6. 说明剪枝改善实际搜索但不自动改变指数／阶乘最坏界。

## 1. 先理解回溯法的算法思想

枚举所有方案通常能保证找到最优解，但方案数可能是指数级或阶乘级。回溯法把这些方案组织为一棵**解空间树**：根结点代表尚未选择，树中结点代表部分方案，叶子代表完整方案。深度优先搜索每次只保存当前路径；返回父结点时撤销刚才的修改，继续尝试兄弟分支。这就是“回溯”。

最优化问题还会保存一个已知可行解，称为**当前最优值**。若能证明某分支即使以最理想方式补全也不可能改进它，就可以不搜索该分支，称为**剪枝**。证明的方向要分清：

| 目标 | 对未完成分支估计什么 | 何时剪枝 |
| --- | --- | --- |
| 求最大值 | 它可能达到的**上界** | 上界 `≤` 已知最大值 |
| 求最小值 | 它必然付出的**下界** | 下界 `≥` 已知最小值 |

通用程序骨架如下。`state` 是当前部分解，`undo` 必须恢复到进入本层前的状态；如果选择根本不可行，就不要递归。

```text
search(state):
    if state 已构成完整解:
        用它更新当前最优解；return
    if 即使乐观补全也无法改进当前最优解:
        return
    for 每个本层可尝试的选择:
        if 选择合法:
            apply(选择)
            search(下一层)
            undo(选择)
```

设计时依次问：**一层决定什么？当前状态记录什么？哪些选择可行？乐观界怎样计算且为什么不会错杀最优解？何时记录完整答案？** 为避免排列问题把同一回路旋转成多个答案，旅行商问题固定起点 `0`。除非另有说明，下文物品、顶点、板和网组都用 **0 起始编号**。

回溯与第 19 章的动态规划不同：背包的 DP 会把相同的“物品下标、剩余容量”子问题合并并保存结果；本章回溯沿不同路径搜索，依靠可行性和界跳过分支。回溯的空间通常较少，也容易输出具体方案，但最坏运行时间仍可能是指数级。

## 2. 应用一：0/1 背包——选或不选

### 问题背景与建模

有 `n` 件不可拆分的物品，第 `i` 件重量 `w[i] > 0`、价值 `v[i] ≥ 0`，背包容量为 `C ≥ 0`。每件物品最多选一次，要求总重量不超过 `C`，总价值最大。例如运输时从若干货物中选择装车方案。这里与第 19 章的 0/1 背包是**同一个问题、另一种求解思路**。

第 `i` 层决定是否选择物品 `i`，因此是高度 `n` 的二叉树。当前状态为 `(i, weight, value, chosen)`：下一个物品下标、已用重量、已得价值和选中的下标。若 `weight + w[i] > C`，选它的分支不可行；不选的分支始终可行。

### 从枚举到剪枝

令 `suffix[i] = v[i] + ... + v[n-1]`。即使把剩余物品**全部免费装进**背包，从当前结点最多也只能得到 `value + suffix[i]`。这可能高估可取得的价值，却绝不会低估，所以是安全上界。若该上界不超过已知最优值，整棵子树都不用搜。预先逆序计算 `suffix`，每个结点就能在 `O(1)` 时间检查这个界。

```cpp
if (value + suffix[i] <= best.maxValue) return;
if (items[i].weight <= capacity - weight) {
    chosen.push_back(i);                  // 选
    dfs(i + 1, weight + items[i].weight, value + items[i].value);
    chosen.pop_back();                     // 撤销
}
dfs(i + 1, weight, value);                 // 不选
```

代码先试“选”，再试“不选”；只有到完整方案时才更新答案。样例 `(重量,价值)=(10,60),(20,100),(30,120)`，容量 `50`：选下标 `{1,2}`，重量 `50`、价值 `220`。接口 `knapsack01(items, capacity)` 返回最大价值、总重量和物品下标；容量为 `0` 或没有物品时返回空选择。输入非法时抛 `std::invalid_argument`。

若界始终无效，二叉树有 `O(2^n)` 个结点，时间为 `O(2^n)`；递归路径、选择数组和后缀数组共需 `O(n)` 额外空间。背包还有更紧的“分数背包”乐观界，但实现需要处理按单位价值排序及原下标恢复；这里使用更容易证明正确的后缀价值界。

## 3. 应用二：最大完备子图——保持两两相邻

### 问题背景与概念

社交关系、通信网络或协作关系可表示为无向图。若一个顶点集合内**任意两个不同顶点之间都有边**，它构成完备子图，也叫**团**（clique）。要求找顶点数最多的团，称为**最大团**。注意“极大团”只表示再加入任何一个顶点都会破坏完备性，未必是全图顶点数最多的团。例如一个孤立的三角形与一个四边形团并存时，三角形是极大团，但不是最大团。

代码输入 `adjacent[u][v]`：有边为 `1`，无边为 `0`，对角线为 `0`；矩阵必须方形、对称，只含 `0/1`。第 `i` 层决定是否选顶点 `i`。当前集合 `chosen` 始终保持是团，这是本题的**不变量**。

### 可行性与上界

只有当 `i` 与 `chosen` 中**每个**顶点相邻，才探索“选 `i`”分支；“不选”分支不改变团。若已选 `k` 个顶点，尚有 `n-i` 个顶点未决定，即使它们全可加入，团的大小最多是 `k+n-i`。该值不超过当前最大团大小时剪枝。

```text
search(i, chosen):
    if |chosen| + (n-i) ≤ bestSize: return
    if i == n: 保存 chosen; return
    if i 与 chosen 中所有顶点都有边:
        chosen.push_back(i); search(i+1, chosen); chosen.pop_back()
    search(i+1, chosen)
```

例如边集 `{(0,1),(0,2),(1,2),(2,3)}` 中，`{0,1,2}` 是 3 个顶点的最大团；`{2,3}` 虽然也不能再扩充，却只有 2 个顶点。接口 `maximumClique(adjacent)` 返回 `size` 和顶点列表；空图返回空团。每个结点的相邻性检查最多 `O(n)`，最坏时间 `O(n2^n)`，矩阵占 `O(n²)`，递归和当前解占 `O(n)`。

## 4. 应用三：旅行商问题——找最短哈密顿回路

### 问题背景与搜索树

一名配送员从仓库出发，访问每个城市**恰好一次**，最后回到仓库，希望总路程最短。这是旅行商问题（TSP）。这里允许有向距离；`cost[u][v] ≥ 0` 是从 `u` 到 `v` 的费用，`-1` 表示没有这条边，主对角线为 `0`。若根本不存在这样的回路，返回费用 `-1` 和空路径。只有一个城市时，约定回路为 `0→0`，费用为 `0`。

固定起点 `0`。状态保存已经访问的路径 `path`、访问标记 `used` 和当前费用 `currentCost`。一层从尚未访问且与末端有边的城市中选下一个；到达 `n` 个城市后，**还必须检查末端到起点的边**，才能算完整可行回路。

### 下界为什么安全

预先求每个顶点的最小出边费用 `minOut[v]`。在部分路径里，已经走过的边已计入 `currentCost`；当前末端和所有未访问顶点各自还需要一条出边，才能构成回路。因此

```text
lowerBound = currentCost + minOut[path.back()]
                         + Σ minOut[v]，其中 v 尚未访问
```

每个 `minOut[v]` 是在**全图**中取的最便宜出边，可能指向已经访问的城市，故界可能过于乐观，但不会超过真实补全费用。如果它已经 `≥` 当前最佳回路费用，继续搜索也无法改进。实际代码在 [`travelingSalesperson`](./backtracking.hpp) 中先检查界，再尝试每个合法下一个城市，递归回来撤销 `used` 和 `path`。

例如四城距离矩阵

```text
     0   1   2   3
0    0  10  15  20
1   10   0  35  25
2   15  35   0  30
3   20  25  30   0
```

最短费用为 `80`，一条最优回路为 `0→1→3→2→0`。完整搜索仍可能考察阶乘级排列；当前每个结点计算界并枚举下一城市需 `O(n)`，最坏时间 `O(n·n!)`，距离矩阵占 `O(n²)`，路径和访问标记占 `O(n)`。非负边权是此剪枝模型的前提；负费用不被接口接受。

## 5. 应用四：电路板排列——控制最大布线密度

### 问题背景与目标

若多块电路板沿一条背板排成一行，同一**网组**可能连接多块板。板间某个切口左、右两侧都有该网组的引脚时，这个网组必须跨过该切口，占用一条布线通道。切口的**布线密度**是跨过它的网组数。目标是选择板的排列，使所有切口中**最大的密度**尽量小，从而降低背板所需的最大布线容量。

输入是 `boards[b][net]` 的 `0/1` 矩阵：`1` 表示板 `b` 有网组 `net` 的引脚。`total[net]` 是整个排列中含该网组的板数；`placed[net]` 是当前前缀中含该网组的板数。于是紧接当前前缀的切口需要网组 `net` 跨越，当且仅当

```text
0 < placed[net] < total[net]
```

这条判定既不要求网组只有两个端点，也不把所有引脚对重复计数。

### 排列树与单调剪枝

解空间是一棵排列树：每层从还未放置的板中选一块追加到前缀。放入板后更新 `placed`，扫描所有网组得到新切口的密度 `crossing`；当前方案的代价为 `max(此前最大密度, crossing)`。未来再放板，**已经出现的切口不会消失**，所以这个当前最大值是完整排列最终目标值的下界。若它已不小于当前最佳排列，直接剪枝。递归返回时从 `placed` 减去该板的引脚，并撤销使用标记和顺序。

例：四块板 `0,1,2,3` 中，网组 A 连接 `{0,2}`，网组 B 连接 `{1,3}`。顺序 `0,1,2,3` 的三个切口密度依次为 `1,2,1`，最大为 `2`；顺序 `0,2,1,3` 的密度为 `1,0,1`，最大为 `1`。接口 `arrangeCircuitBoards(boards)` 返回 `minDensity` 与板下标顺序。单板、没有网组或空输入的最优密度都是 `0`。

排列数最坏为 `n!`，每个结点需扫描网组并尝试未用板，最坏时间 `O((n+m)n!)`，其中 `m` 为网组数；输入矩阵占 `O(nm)`，辅助数组及递归占 `O(n+m)`。

## 6. 四题如何对应同一个模板

| 问题 | 一层的选择 | 必须维持的状态或不变量 | 剪枝依据 |
| --- | --- | --- | --- |
| 0/1 背包 | 选或不选一件物品 | 总重量 `≤ C` | 当前价值 + 剩余价值上界 `≤` 已知最大价值 |
| 最大完备子图 | 选或不选一个顶点 | 已选顶点两两相邻 | 已选数 + 剩余顶点数 `≤` 已知最大团大小 |
| 旅行商 | 下一站选哪个城市 | 路径中城市不重复，边存在 | 当前费用 + 必需出边费用下界 `≥` 已知最短费用 |
| 电路板排列 | 下一块板放哪块 | 前缀板不重复，已统计跨线 | 已出现的最大切口密度 `≥` 已知最小密度 |

前两题搜索的是**子集树**，后两题搜索的是**排列树**。剪枝会减少实际访问的结点，却不改变最坏阶数量级。界必须“乐观”，而且只在已有可行答案时才能拿最优值比较。找到一个部分方案时，不能把它误当作旅行商或电路板排列的完整答案。

### 为什么剪枝不会漏掉更优解

完整正确性可拆成三条：

1. **覆盖性：** 不剪枝时，每个合法完整方案对应解空间树的一条路径；每层枚举了全部合法下一选择。
2. **状态恢复：** 递归返回后，`chosen/path/order`、`used`、`placed` 等恢复到进入分支前的值，因此不同分支互不污染。
3. **界的安全性：** 最大化分支内任意完整解都不超过上界，最小化分支内任意完整解都不低于下界。只有当界已不能严格改善当前可行解时才剪枝。

若把背包上界误写成“当前价值”、或把 TSP 下界写成一个可能高于真实补全费用的估计，第 3 条就失败。搜索可能更快，却不再保证最优。

### 实现成本不只看叶子数

深度优先回溯复用当前选择数组、标记和统计，搜索辅助空间通常为 `O(深度+状态)`。每个内部结点还会做相容性检查、扫描剩余顶点或网组、计算界；所以最大团写成 `O(n2^n)`、TSP 写成 `O(n*n!)`，而不是只写方案数。返回的最佳方案另占线性空间。
