## 目标与约束

把现有第 1–21 章组织为可阅读、可推演、可运行、可自测的中文课程。读者已具备基本 C++ 语法，指针、模板和递归仍需配合例子解释。讲义必须以实际实现和测试为依据，区分已实现、只作概念介绍、尚未覆盖三种状态；不把测试通过等同于算法库绝对完备。

所有讲义保留在各章 README；总 README 提供课程地图、学习路线、运行方式、覆盖边界和审查结论；AGENTS.md 固化后续代码与讲义协同维护规范。保留 C++11、独立 assert 测试和现有 ADT。只在发现影响教学的可复现问题时修改代码，并添加对应验证。
